# YT Advertisement Inventory Loader

## Overview

A single 4.8-second, loop-friendly ManimCE scene for the YT Advertisement inventory management system. The visual language uses the app palette: deep navy background, cyan operational signal, gold inventory accent, and compact dashboard-style labels.

## Narrative arc

The loader begins with the YT Advertisement wordmark, brings the inventory system mark online, reveals three operational status cards, then completes a bright synchronization sweep across the progress rail. It is intentionally silent and text-light so it can be used as a reusable web loading component.

## Scene: InventoryLoader

- **Duration:** 4.8 seconds; no narration.
- **Purpose:** Communicate that the operations dashboard is connecting materials, machines, and job-card data.
- **Visual elements:** Brand header, central YT system mark, rotating cyan sync ring, three status cards for materials/machines/job cards, six-segment progress rail, subtle grid background.
- **Animation beats:** Fade in header and central mark; reveal status cards with staggered motion; rotate the sync ring while the progress rail illuminates; hold on the connected state briefly.
- **Technical notes:** `plugin: none`; Manim Community Edition; no external assets; export as MP4 for a muted looping `<video>` loader with a CSS fallback.

## Audio Sync

No narration or audio. The animation is designed for silent looping in the web application.
